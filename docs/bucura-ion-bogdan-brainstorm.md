## Idei de proiect

1. **Dashboard IoT pentru monitorizare și control** — dispozitiv ESP cu senzori (temperatură, umiditate, calitate aer) trimite date prin WiFi/MQTT către un backend; un dashboard web (Vue + Firebase) afișează totul în timp real cu grafice, alerte și posibilitate de a trimite comenzi înapoi către dispozitiv (ex. pornireventilator la prag de temperatură). Pipeline complet senzor → cloud → ecran → control.

2. **Smart room controller** — microcontroler + relee + senzori de mișcare/temperatură/lumină într-o sală de curs sau cameră. Interfață web pentru control remot (lumini, aer conditionat) + automatizări pe baza senzorilor (ex. stinge lumina dacă nu e nimeni). Focus pe arhitectura feedback-ului: hardware citește → web decide → hardware execută.

3. **Sistem de alertare ambientală** — rețea de noduri ESP cu senzori distribuți în mai multe locații, fiecare publică pe MQTT. Platforma web centralizează datele, detectează anomalii și notifică prin dashboard + eventual push/email. Scop: scalabilitate horizontală pe partea de hardware + vizualizare centralizată pe web.
