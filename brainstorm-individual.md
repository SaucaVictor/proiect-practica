## Ce vreau să învăț

Vreau să duc ce știu cu Arduino un pas mai departe: comunicație wireless (WiFi/MQTT), integrare cu o platformă web în timp real și un pipeline complet hardware → cloud → UI. Mă interesează să construiesc ceva bine gândit ca arhitectură, de la senzor până la ecran, nu doar piese separate.

---

## Idei de proiect

1. **Dashboard IoT pentru monitorizare și control** — dispozitiv fizic (Arduino/ESP) care trimite date de senzori (temperatură, umiditate, consum, etc.) în timp real către o platformă web. Interfața permite și trimiterea de comenzi înapoi către dispozitiv. Stack posibil: Arduino/Wemos + Firebase Realtime Database + frontend web.

2. **Sistem de automatizare cu interfață web** — senzori și actuatoare controlate dintr-un panou web: lumini, prize, alerte, istoric date. Arhitectură modulară — fiecare modul fizic separat, toate vizibile într-un singur dashboard.

3. **Stație meteo IoT cu vizualizare web** — senzori de mediu (temperatură, umiditate, presiune, UV) montați fizic, date trimise wireless și afișate pe un site cu grafice și istoric. Simplu, util și demonstrabil.

## Rol în echipă

Primar: **hardware/embedded** — programare microcontrolere, integrare senzori, comunicație cu serverul.

Secundar: **glue code / backend simplu** — tot ce leagă hardware-ul de platforma web (API, listener de date, logică de control).

Deschis și spre: frontend web dacă echipa are nevoie — știu să fac, nu e preferința principală dar nu e o problemă.
